# Recording Instructions

## Option 1: AI Voiceover (Recommended)
1. Use one of these tools:
   - **Murf.ai** - Best for product demos
   - **Descript** - Easy editing
   - **Clipchamp** - Free, built into Windows
   - **Narakeet** - Script-to-video

2. Copy each scene's narration
3. Generate voiceover clips
4. Sync with screen recording

## Option 2: Screen Recording Setup

### macOS:
```bash
# Start QuickTime Player screen recording at retina resolution
# Or use OBS Studio for more control
```

### Recording Settings:
- Resolution: 1920x1080 or 2560x1440
- Frame Rate: 30 or 60 fps
- Audio: None (add voiceover later)

### Run the demo:
```bash
cd e2e && npm test -- --project=demo tests/demo-showcase.spec.ts
```

## Post-Production Tips

1. **Trim** the beginning/end
2. **Add** intro/outro slides
3. **Sync** voiceover to video
4. **Add** subtle background music (optional)
5. **Export** at 1080p or 4K

## Recommended Tools for Editing

- **Descript** - Text-based video editing
- **DaVinci Resolve** - Free, professional
- **Clipchamp** - Simple, Windows built-in
- **iMovie** - Simple, macOS built-in
